# DyPO-ICU

Dynamic prediction of outcomes in intensive care — this project is organized across several repositories, each covering a specific part of the pipeline.

## Project components

- **[Preprocessing Time Series](https://github.com/mpoette/preprocessing_time_series)**
  ICU data extraction and preprocessing pipeline.

- **[TSFE Methodology](https://github.com/mpoette/TSFE_methodologie)**
  Time series feature extraction and deep learning benchmark for outcome prediction.

## About

This work is developed at CHU Toulouse, in collaboration with IRIT (CNRS UMR5505) and RESTORE (Inserm UMR1301).Z
